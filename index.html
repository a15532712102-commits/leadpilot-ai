要真正自动搜索与大模型分析，需要你部署私有后台。API 密钥仅放在后台，不放到这个公开网页里。

联网搜索需要 Brave Search API；AI 分析需要 OpenAI API。API 费用由各服务提供商按实际用量计算。

📦 备份与导出

客户信息默认保存在当前手机浏览器中，不会自动云同步。建议定期备份；Safari 清理网站数据可能使客户库丢失。

📲 全手机使用步骤

1
下载 index.html先保存到 iPhone“文件”App
2
通过 GitHub Pages 发布Safari 登录 GitHub，创建仓库并上传 index.html，开启 Pages
3
添加到主屏幕用 Safari 打开发布网址 → 分享 → 添加到主屏幕
4
开始寻找客户不配后台也能搜索、筛选、管理及生成基础开发话术
完全自动搜索与 AI 分析需额外配置 Cloudflare Worker + Brave Search + OpenAI，安装包内附源代码和设置说明。
